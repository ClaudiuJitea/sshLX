# Phase reports

Each phase ended with a clean build, all tests passing, and
`tools/verify-putty-untouched.sh` reporting
`OK (722 files match)`. For the overrides at any point, see
`PUTTY-OVERRIDES.md`; it is listed per phase below.

## Phase 0: Engine extraction

**What changed**
- **Build system.**
  - `CMakeLists.txt` and `cmake/putty-config-checks.cmake` re-implement
    PuTTY's configure probes; `cmake.h`, `sbcsdat.c` and `cmake_commit.c`
    are generated into `build/generated`.
  - `cmake/putty-sources.cmake` gives the explicit source list: 247 PuTTY
    files compiled unchanged, with override lookup.
  - A guard refuses build directories inside the PuTTY tree.
- **Engine** (`src/engine/`):
  - the public C API, `sshlx_engine.h`;
  - session lifecycle;
  - Conf reflection and PuTTY-format saved sessions.
- **Front-end glue** (`src/engine/frontend/`), replacing GTK's
  `window.c`/`dialog.c`/`gtk-common.c`/`putty.c`:
  - host loop, platform hooks;
  - Seat with async in-tab prompts, TermWin, LogPolicy;
  - the keyboard port of `key_event`;
  - the `dlg_*` bridge.
- **Tests:**
  - `engine_api_test`: reflection, saved sessions, and PuTTY's config box
    with 250 controls on 33 panels driven by PuTTY's handlers;
  - `engine_sessions_test`: serial over a pty, raw, telnet and SSH against
    PuTTY's `uppity`, all concurrent; isolation, reconnect, remote exit,
    EACCES;
  - `putty-untouched`.

**Overrides:** none.

**Behaviour differences:** none at engine level.

## Phase 1: Qt6 terminal widget and tabbed window

**What changed**
- **Host loop:** `QtHostLoop` uses QSocketNotifier, QTimer and queued
  calls, with one persistent notifier per fd. PuTTY's `uxsel` re-registers
  fds and Qt allows only one notifier per (fd, type); found by the
  12-tab test.
- **`TerminalView`:**
  - QPainter into a DPI-aware backing image;
  - PuTTY's colour, bold, dim and cursor rules; double-width/height lines;
  - IME, mouse, wheel and clipboard (PRIMARY + CLIPBOARD);
  - shortcut arbitration.
- **`SessionWidget`:** in-tab prompt bar with trust marker, reconnect bar
  with the dialout/uucp explanation for EACCES, event log, context menu with
  special commands.
- **Generic `SettingsDialog`** renders PuTTY's complete configuration box.
- **Tabs, menus, About box** crediting PuTTY.
- **Test:** `app_gui_test` (offscreen).

**Overrides**
- New: `unix/serial.c`. A static fd index went stale when one of several
  serial sessions closed, so the others stopped receiving.
- The regression test fails on PuTTY's original file and passes with the
  override.

**Behaviour differences**
- Server-initiated resizes are not honoured in tabs.
- Custom named X clipboards map to CLIPBOARD.
- Tabs stay open with a reconnect bar where PuTTY would close the window
  (configurable).

## Phase 2: Connection tree

**What changed**
- `ConnectionTree` (Qt Core, unit-tested) stores folders, icons,
  descriptions, panel, favourites, inheritance and ordering in
  `~/.config/sshLX/connections.json`.
- `ConnectionStore`:
  - zero-step import of PuTTY sessions;
  - create, duplicate, rename and delete act on the PuTTY session files;
  - effective Conf = saved session plus inherited folder values.
- Model with drag & drop as real row moves; Connections panel with toolbar,
  filter and context menu.
- Import/export of the tree with the sessions' settings bundled.
- Tests: `model_test` and GUI tree tests.

**Overrides:** `unix/serial.c` (unchanged this phase).

**Behaviour differences:** a connection's name is its PuTTY session name;
renaming renames the session.

## Phase 3: Property grid, generic settings dialog, inheritance

**What changed**
- Config panel built on `QTreeView` with delegates for text, password,
  number, enum, bool, colour, font, file and key=value maps.
- Categorised and A→Z views, help text, immediate saving.
- **Contents:**
  - 86 curated properties in the spec's categories (Display, Connection,
    Protocol, Terminal, Window, Appearance, Logging, Proxy, SSH, Tunnels);
  - every other Conf key under "All Settings (advanced)", generated by
    reflection.
- **Inheritance:**
  - per key: Inherit column on connections, Set-here column on folders;
  - italic inherited values with their source folder named;
  - editing an inherited value makes it the connection's own.
- **Full settings…:** PuTTY's complete dialog for connections ("Save" or
  "Open"), and for folders (changed keys become folder values).
- **Engine:** Conf getters no longer abort on keys absent from a Conf
  (PuTTY asserts presence).

**Overrides:** `unix/serial.c` (unchanged this phase).

**Behaviour differences:** none. The grid writes through PuTTY's Conf and
storage, like PuTTY's dialog; the dialog itself is PuTTY's.

## Phase 4: Serial auto-detection

**What changed**
- **`src/platform/serialdetect`** (plain C):
  - libudev loaded via `dlopen`, so no build dependency on its headers;
  - a sysfs-poll fallback;
  - reports ttyUSB, ttyACM, real ttyS and rfcomm devices;
  - device details: by-id path, VID:PID, manufacturer, product, serial
    number, driver;
  - tested against a mocked sysfs tree.
- **Serial Ports** section in the tree, updated live. Detection took 152 ms
  in the polling test; udev is instant.
- **Device rules** (`~/.config/sshLX/serial-rules.json`):
  - ask / auto-connect / ignore;
  - a line template, default 115200 8N1;
  - auto-reconnect;
  - matched by the stable by-id path, or VID:PID+serial.
- **Notifications:** non-modal banner (Connect / Always / Ignore / Never /
  Settings) and an optional D-Bus desktop notification.
- **Unplug / replug:** an unplugged device disconnects its tab, and
  re-plugging reconnects the same tab even under a new device name.

**Overrides:** `unix/serial.c` extended:
- serial I/O errors end the session instead of calling `exit(1)`;
- no `uxsel_set(-1)` after close.

Regression test added.

**Behaviour differences:** the template uses no flow control; PuTTY's
default is XON/XOFF.

## Phase 5: Qt Advanced Docking System, persistence, polish

**What changed**
- **Qt ADS 4.4.1:**
  - fetched as a shared library and patched to avoid Qt private headers;
  - panels and sessions are dock widgets;
  - split side by side or stacked, floating windows;
  - middle-click close, tab drop-down;
  - Ctrl+Tab/PgUp/PgDn across areas;
  - named "panel" areas.
- **Persistence:**
  - dock layout and window geometry;
  - open tabs, optionally restored on startup into their previous areas;
  - crash breadcrumb with an offer to reopen.
- **Options dialog:** behaviour, serial, configurable shortcuts with
  conflict check, opt-in keyring.
- **Keyring:** QtKeychain 0.15.0 (shared); "Password (keyring)" property;
  passwords never in files.
- `RLIMIT_NOFILE` raised at startup.
- README, manual checklist, these reports.

**Overrides:** `unix/serial.c` (unchanged this phase).

**Behaviour differences:** server resize requests are ignored in floating
windows too (see `ARCHITECTURE-NOTES.md` §11.3).
